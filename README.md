# Simple Vite (React) App

A small React app built with Vite to practice the **useState** hook. It includes four mini features, each managing its own state.

## Features

- **Dark / Light mode toggle**: switch the theme with one click.
- **Like / Unlike post**: toggle a like on a post and see the status update instantly.
- **Counter**: increase, decrease, and reset a number.
- **Simple form**: enter details and see the submitted data displayed on the page.

## Tech Stack

- React
- Vite
- JavaScript (ES6+)
- CSS

## Concepts Practiced

- `useState` hook for managing component state
- Conditional rendering
- Handling events (`onClick`, `onChange`, `onSubmit`)
- Controlled form inputs
- Displaying state data in the UI

## Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/khushighediya1406-web/react-usestate-lab.git
   ```
2. Go to the project folder
   ```bash
   cd react-usestate-lab
   ```
3. Install dependencies
   ```bash
   npm install
   ```
4. Start the development server
   ```bash
   npm run dev
   ```
5. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build for Production

```bash
npm run build
```
